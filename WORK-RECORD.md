# Work record

A module counts as done only when its folder is in this repository with:

1. One to three artifacts I made (a query, a rule with its test, a script, a config, a short report).
2. A `README.md` with the five sections: What it is, Reproduce, Evidence, Skills shown, What it does not show.
3. A `NOTES.md` of five lines or fewer: what I did, one thing that went wrong, what I would check next.

Reading a lesson does not count. Passing a checker does not count until the work is here.

## Before every push

- Search the files for real names, home addresses, real IP addresses outside the lab ranges, passwords, keys and tokens.
- Confirm every data file is fake, generated, or from my own lab.
- Leave out memory images, disk images, virtual machine files and packet captures of my home network.
- Leave out lab kit code I did not write, any sample binaries, and anything that could work as attack tooling. Publish the report and the detections instead.

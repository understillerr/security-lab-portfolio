# Security lab portfolio

Riley Understiller. IT student with a cybersecurity focus, building toward SOC analyst, detection engineering and security engineering work.

This repository holds work I did myself in my own lab: queries, detection rules with their tests, scripts and short reports. It is new. Folders appear as work is finished, and an empty list means nothing is finished yet.

## How to read it

One folder per module of the course I am working through, named `module-NN`. Each folder has a `README.md` with the same five sections:

- **What it is**: the task in two or three sentences.
- **Reproduce**: the exact command to run and the output to expect.
- **Evidence**: the files that back each claim.
- **Skills shown**: what the work demonstrates, stated plainly.
- **What it does not show**: the limits. Lab data is not production data.

`WORK-RECORD.md` lists every module and whether its work is here yet.

## Rules I hold this repository to

- All data is fake, generated, or captured from my own lab machines. Nothing comes from an employer, a school system or anyone else's network.
- No credentials, keys, tokens or personal details. Every commit is checked before it is pushed.
- Defensive work only: detections, analysis, hardening and reports. No malware samples and no attack tooling.
- If something here is wrong, the fix is a new commit that says what was wrong.

Windows host, WSL2 Ubuntu 24.04, VirtualBox guests (Windows 11 evaluation, Ubuntu, Kali). Free tools only.
